# Tách nền giao diện dùng chung cho TTG

**Goal:** Tách layout, header/menu/footer, thẻ sản phẩm, CSS và JS để màn danh mục/chi tiết sản phẩm và tin tức sau này gọi lại, giữ nguyên giao diện demo hiện tại.

**Architecture:** Template ES module thuần nhận dữ liệu qua tham số, được ghép ở bước build và xuất HTML hoàn chỉnh. Không dùng fetch partial ở runtime, không thêm framework/server nghiệp vụ. Script build đọc snapshot và ghi đầu ra; component không có I/O.

**Tech Stack:** Node.js ES modules, HTML tĩnh, Tailwind CSS v4.3.0, JavaScript thuần, Cheerio và Node test runner.

## Ràng buộc đã chốt

- Chỉ tách nền dùng chung; chưa dựng bốn màn sản phẩm/tin tức.
- Giữ 171 vị trí sản phẩm, 7 nhóm danh mục, 6 nhóm sale; dữ liệu và tài nguyên snapshot giữ nguyên.
- Giữ class, DOM, ID/ARIA, breakpoint, màu sắc và tương tác trình bày hiện có.
- Không thêm tìm kiếm thật, giỏ hàng, đăng nhập, mua hàng, API hoặc lưu nghiệp vụ.
- Video giữ header riêng, nội dung và player hiện tại.
- Giữ hosting tĩnh; output CSS vẫn là một file.
- Browser dùng Chrome DevTools dedicated profile; fallback duy nhất là Codex in-app Browser và phải thông báo.
